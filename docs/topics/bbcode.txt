[B][COLOR=#0099ff]About[/COLOR][/B]
GitEconomy is a Vault-compatible economy plugin focused on core commands: balance, pay, baltop, and admin eco controls. No banking subsystem.

Need help? Contact GitEpildev via GitHub: [URL='https://github.com/GitEpildev']github.com/GitEpildev[/URL]
Website: [URL='https://developer.epildevconnect.uk/']developer.epildevconnect.uk[/URL]

[B][COLOR=#0099ff]Commands[/COLOR][/B]
[LIST]
[*][B]/balance[/B] ([icode]/bal[/icode]): View your balance
[*][B]/balance <player>[/B]: View another player's balance ([icode]giteconomy.balance.others[/icode])
[*][B]/eco <give|take|set> <player> <amount>[/B]: Admin balance controls ([icode]giteconomy.eco[/icode])
[*][B]/baltop[/B] ([icode]/top[/icode]): Show top balances
[*][B]/pay <player> <amount>[/B]: Send funds to another player ([icode]giteconomy.pay[/icode])
[*][B]/currency [currency][/B]: Set or view preferred currency ([icode]giteconomy.currency[/icode])
[*][B]/giteconomy reload[/B]: Reload configuration ([icode]giteconomy.admin[/icode])
[*][B]/giteconomy cleanup[/B]: Remove orphaned player data ([icode]giteconomy.admin[/icode])
[*][B]/giteconomy database info|test|reset[/B]: Database utilities ([icode]giteconomy.admin[/icode])
[/LIST]
